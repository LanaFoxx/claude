Three decisions

Three answers in the first screen. Progress, access end date and class type sit under the title, with one orange button that changes by state: Start class, Continue: Lesson 9, Print your certificate.

Status by text and icon, never color alone. Every row says Complete, In progress or Not started next to its icon. The current lesson gets the only tinted row.

Completed sections collapse on mobile. A long class opens to the current section; finished parts become one summary row each, so the next lesson is one tap away.
