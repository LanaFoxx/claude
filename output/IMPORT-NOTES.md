Files: `tn-header.json`, `tn-footer.json`, `tn-homepage.json`. All three are generated by `tools/build_templates.py`. To change a value, edit the script and re-run it (`python3 tools/build_templates.py`) instead of editing the JSON by hand.

> **Status: not render-tested yet.** The JSON has been checked statically: it parses, all 227 IDs are unique, there are no Sections or Columns, every nested container is Full Width, there is one H1, every phone link has `tn-call`, and the form ID and redirect are set. ## 3. Import order

Go to **Templates → Saved Templates → Import Templates** and import the files in this order:

1. **`tn-header.json`**
   - Open it in Theme Builder and publish it with the display condition **Include → Entire Site**.
2. **`tn-footer.json`**
   - Publish it with **Include → Entire Site**.
3. **`tn-homepage.json`**
   - Create a page called "Home".
   - In Page Settings, set **Page Layout → Elementor Full Width**. This removes Hello's page title and the content-width wrapper.
   - Open the page in Elementor, then use **Add Template → My Templates → TN Homepage → Insert**, and publish.
   - Go to **Settings → Reading** and set a static front page: Home.
4. Create a placeholder **`/thank-you/`** page so the form redirect doesn't 404, and a **`/request-an-estimate/`** page, because the header and the mobile bar link to it.

## 8. Differences from the reference, and why

1. **Responsive columns follow the brief's counts, not CSS auto-fit.** The reference reflows with `auto-fit/minmax`. Elementor sets columns per breakpoint, so each grid uses the brief's counts (for example Trust 5/5/3/1, Projects 4/4/2/1, Why 3/3/2/1, Footer 5/5/2/1). Between 981 and roughly 1120px, a few two-column splits (Who We Are, Away, Estimate) stay side by side, where the reference would already stack them.
2. **Mobile breakpoint 600 vs the reference's 760.** The reference hides the utility bar and header buttons, and shows the call icon and sticky bar, at 760px. The brief sets Mobile to 600. Scoped CSS (`@media (max-width:760px)`) in `#tn-header` and on the call bar keeps the reference behavior from 601 to 760px, so the header never overflows in that range.
3. **The sticky call bar is `position: fixed`**, not CSS sticky. A footer template can't be sticky against the whole page. The footer gets 76px of bottom padding up to 760px so the bar never covers footer content.
4. **The Away for the Season section is full-bleed** (Full Width, no side padding), exactly as in the reference. It is the one section that is not Boxed 1280.
5. **Header layout uses a grid container.**
   - Columns are `auto 1fr auto` on desktop and `1fr auto` at the laptop breakpoint and below.
   - This reproduces the reference's space-between layout and keeps the nav centered between the logo and the buttons. The nav never wraps (scoped CSS).
   - Grid containers are Elementor Flexbox Containers set to Grid. No Sections or Columns are used.
6. **Icons.**
   - Stars, phone, camera and chevron use Font Awesome (solid) through native widgets, so they are slightly heavier than the reference's thin line icons.
   - The six "Why Top Notch" icons are the reference's exact line SVGs in HTML widgets, because no native icon set matches them.
7. **Photo slot stripes are omitted.** The diagonal stripe texture in the reference is a placeholder look. Per the brief, slots carry only the background color.
8. **Dropdown submenus aren't designed in the reference.** They use Smokehouse #1E1A16, a Hairline border, 14px Manrope 500, and a Hairline hover background.
9. **Hover states:** primary buttons go to #D9A66B, outline buttons get an amber border, and nav links and amber text links go to #D9A66B. The reference has no hover styles because its colors are inline.
10. **Form field gaps:** Elementor uses one row gap (20px), where the reference uses 16px inside the field grid and 20px below it.
11. **Header estimate button** links to `/request-an-estimate/`, not `#estimate`, because the header appears on every page. The homepage hero and Away buttons still link to `#estimate`.
12. **"Visit Top Notch Logworks →"** links to `https://topnotch-logworks.com/`.
13. **Fluid sizes are stepped per breakpoint.** The reference's `clamp()` sizes are set as desktop / laptop / tablet / mobile values:
    - H1: 80 / 68 / 52 / 40
    - H2: 56 / 48 / 40 / 36
    - Card H3: 42 / 36 / 32 / 32
    - Section padding: 128 / 112 / 96 / 72
