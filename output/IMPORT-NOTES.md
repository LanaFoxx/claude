## 2. SVG icons

The JSON references these icons by Media Library URL. On import, Elementor downloads each one from that URL into the new site's Media Library.

- **The URLs point to staging197.** Staging must still be online when you import.
- **If staging is gone,** upload the files in `output/icons/` and re-select them:
  - The six Why icons and the two social icons are Phosphor Light (MIT), taken exactly from the reference.
  - The phone, camera, menu and chevron files are the reference's line glyphs.
- **To repoint the JSON at the new site,** update `tools/icon_map.json` with the new IDs and URLs and re-run the script.

**Known limit:** the Nav Menu submenu indicator must be a font icon. An uploaded SVG there crashes the Pro Nav Menu render (tested). The chevrons use Font Awesome `chevron-down`, set to 10px at 60% opacity.

## 4. Import order

Go to **Templates → Saved Templates → Import Templates**:

1. **`tn-header.json`:** publish with the condition **Include → Entire Site**.
   - The main row is transparent and absolutely positioned over the top of the first section.
   - Every page needs a dark first section with at least about 200px of top padding (the hero has exactly 200px).
2. **`tn-footer.json`:** publish with **Include → Entire Site**.
3. **`tn-homepage.json`:**
   - Create the page "Home" with **Page Layout → Elementor Full Width**.
   - Use Insert template, then publish.
   - Go to **Settings → Reading** and set the static front page to Home.
4. **`tn-request-an-estimate.json` → `/request-an-estimate/`** and **`tn-thank-you.json` → `/thank-you/`**, imported the same way.
   - The header pill and the mobile bar's "Free Estimate" link to `/request-an-estimate/`.
   - Both forms redirect to `/thank-you/`.

## 8. Differences from the reference, and why

1. **Fluid sizes are stepped per breakpoint.** The reference's `clamp()` values are read off at 1440 / ~1300 / 980 / mobile and set as desktop / laptop / tablet / mobile:
   - H1: 86 / 78 / 59 / 44. The brief says 88, but the reference renders 86 at 1440.
   - H2: 60 / 55 / 41 / 36
   - What We Do H2: 43 / 39 / 32 / 32
   - Quote: 48 / 43 / 32 / 30
   - Section padding: 128 / 117 / 88 / 80
   - Between 1360 and 1440, sections run up to about 35px taller than the reference, and up to about 35px shorter just below 1360.
2. **Breakpoint 600 vs the reference's 760.** The brief sets Mobile to 600. Scoped CSS keeps the reference behavior from 601 to 760px:
   - The top bar, the builders link and the header pill are hidden.
   - The call circle, the mobile call bar, and the review arrows below the quote are shown.
3. **The mobile call bar is `position: fixed`.** A footer template can't be CSS-sticky against the page. Up to 760px, the footer gets 70px of extra bottom padding so the bar never covers content.
4. **Review stars are drawn in CSS.** The Testimonial Carousel has no rating field, so the 5 Deep Amber stars are a CSS image above each quote, not editable per review. Add reviews in the carousel's Slides list: name = person, title = town. The "1 / 2" counter is the carousel's fraction pagination.
5. **The stats strip is its own section,** "Reviews / Stats Strip", directly under Reviews, so it stays inside the Boxed 1280 rule. `#reviews` covers the testimonial block only. **Changed on request:** the "Read all reviews →" link is removed and the three stats are centered.
6. **Responsive switches that the reference does with auto-fit** use explicit columns:
   - The index lists go to 1 column below 512px.
   - The form fields stack below 536px.
   - Projects use flex-grow 2 : 1 : 1 with basis 560 / 280 / 280, exactly like the reference.
7. **The header's main row** is a Grid container (`auto 1fr auto` on desktop, `1fr auto` at 1359px and below), not CSS flex space-between. Grid containers are Elementor Flexbox Containers set to Grid; no Sections or Columns are used.
8. **Text links are Button widgets** with a transparent background and 14.5px vertical padding, which gives a 44px tap target. The underline (1px, 7px offset, rgba(242,236,227,0.4), or Deep Amber on light) is scoped CSS on each widget.
9. **Not in the reference, so styled to match:**
   - Dropdown submenus: #14110E background, no borders, 14px Manrope 500, amber hover.
   - The menu button's open panel: the same, with one hairline at the top.

## 9. Issues found during testing (fixed in the JSON)

- **An uploaded SVG as the Nav Menu submenu icon crashes the page render.** Switched to the Font Awesome chevron.
- **The Testimonial Carousel's defaults:**
  - 20px slide padding.
  - Italic, gray quote text.
  - Arrows and counter clipped inside the swiper on mobile.

  All three are overridden in scoped CSS.
- **A general field `background` rule wiped the select chevron.** The select rule now has higher specificity.
- **Testing tip:** SmartMenus only opens dropdowns on hover after it detects a real mouse. A scripted test that jumps the pointer won't open them.
