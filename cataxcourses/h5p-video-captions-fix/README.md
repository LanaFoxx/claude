# H5P.Video 1.5.13 — YouTube captions off by default

Problem: H5P.Video 1.5.12 calls `player.loadModule('captions')` for YouTube videos. YouTube then switches its
auto-generated English captions on, and because that track is not in the tracklist H5P shows no CC button,
so students cannot turn captions off.

Fix (`youtube.js.patch`, generated by `patch3.py`): turn captions off once YouTube reports the auto track,
offer that track under H5P's CC button, and load/unload YouTube's captions module when a student toggles CC.
Tested in Chromium by serving the patched script in place of the live one: captions start off, CC button
appears, CC on/off works, no script errors.

Install: Site administration → Plugins → Activity modules → H5P → H5P Libraries → Upload Libraries,
choose `video-1.5.13.h5p`, tick "Only update existing libraries", Upload. The library list should then show
Video (1.5.13). To roll back, upload the original 1.5.12 files with a higher patch version.

Note: an official H5P.Video update installed later would replace this patch.
